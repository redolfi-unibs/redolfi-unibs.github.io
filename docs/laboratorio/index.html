Laboratorio

I sorgenti degli esercizi di laboratorio, Java e C, stanno su GitHub, in un repository pubblico che cresce durante il corso: max-ai4res/pajc-lab27. Le tracce arrivano prima di ogni laboratorio; le soluzioni scritte insieme in aula si aggiungono a fine lab.

Ogni esercizio Java è un progetto Eclipse completo, da importare nel workspace con File > Import > Existing Projects into Workspace. Accanto a ogni cartella c'è anche il suo archivio .zip, se preferite partire da quello. Gli esercizi in C sono cartelle di sorgenti da aprire in Visual Studio Code.

Come scaricarlo

Se usate git, il repository si clona una volta sola e poi si aggiorna da solo a ogni lezione:

git clone https://github.com/max-ai4res/pajc-lab27.git
cd pajc-lab27
git pull    # prima di ogni lab, per avere gli esercizi nuovi

Se non usate git, dalla pagina del repository il pulsante Code > Download ZIP scarica tutto il materiale così com'è al momento: in quel caso lo scaricate di nuovo quando aggiungo un esercizio.

Elenco sempre aggiornato

Quali esercizi ci sono e a che cosa servono è scritto nel README del repository: è l'elenco che aggiorno lezione per lezione.
